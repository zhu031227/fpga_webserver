## 四、本日实际修复的三个真实 bug(P2, 已上板验证)

1. **固件时钟冻结**: 0x07(local_time_l) 是"写 0x06 拍照"锁存器, 全固件无人写 0x06 → 时钟恒 0
   → ISN 恒 0(pcap 铁证: SYN-ACK seq 0)、全部 TCP 定时器死转、TIME_WAIT/idle 永不过期、
   16 连接槽耗尽后新 SYN 被静默丢弃(历史"板子越用越死")。修复: LCPU_LOCAL_TIME64()
   写 0x06 触发锁存后读 0x07/0x08 拼 64 位。
2. **定时常数 20.6× 错标**: 常数按 50MHz 标, 实测自由计数器 1.035GHz(4.15s 回卷)。
   修复: 常数按实测速率重标 + uint64 运算。
3. **LAST_ACK 僵尸槽**: 板卡 FIN|ACK 从未上线 + final-ACK 精确匹配过苛 → 端口复用后新 SYN
   被僵尸吞掉(pcap 全程抓获)。修复: 收 FIN 后 RST|ACK 立即关闭。
   验证: 密度矩阵 2s/0.5s/0.1s 全过, 25 连接 0.2s 压力 25/25(旧固件必死)。
